# readme
Descripcion de nuestro sitio web, cuales funciones tiene, para que sirve, que hace, etc
Esta pagina se encarga de ayudar al usuario a ubicar los laboratios del liceo al usuario 
La pagina Index que es la principal muestra informacion de los labs resumida no completa con los horarios en cual los labs se abre y se cierra, tambien los cursos que van a ellos

La pagina de contactos sirve para contactar al moderador de la pagina, para notificarle de un error, error en la informacion o una recomendacion 
La pagina de Presentacion se encarga de dar una presentacion y el porque hicimos esta pagina y cual es el proposito de ella
La pagina de reserva sirve para poder crear una hora para el uso de un laboratio, pone el dia y la hora y el correo llega al moderador de los laboratorios para confirmar la hora, si aquella hora ya esta ocupada no se mandara y la pagina notificara que use otra hora 
La pagina de Reserva con exito sale cuando la reserva a concluido de manera correcta, mostrando un ticket de la hora y dia en cual el laboratio sera usado, se recomienda tomar una captura de pantalla y guardarlo para mostrarlo 
La pagina sobre mi y Sobre miV2, se encarga de mostrar informacion de los admins de la pagina, con un breve resumen y mostrando el correo electronico para comunicarle sobre algo relevante de la pagina
La pagina de los laboratios, se encarga de redactar cada uno de los laboratios, mostrando el estado tanto del sitio y de los equipos, con los sistemas operativos que tienen en general
